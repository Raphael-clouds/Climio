# Climio🌤️
Climio is a responsive app web made for searching the weather in every device I made it with:

- React
- JavaScript
- HTML
- CSS

## What you can do?
In this page you can discover the weather in every city in this world and learn about the forecast of the different places in the world.

A large part of this project was a continuous learning experience. With every single code line i felt that i grew up like a programmer and web developer.
